Zero Cross (Tic-Tac-Toe) Game
Description:
    Zero Cross (Tic-Tac-Toe) is a classic 2-player game where players take turns marking ‘X’ or ‘O’ in a 3×3 grid. The first player to align three marks in a row, column, or diagonal wins!
How to Play:
    Player 1 plays as ‘X’ and Player 2 as ‘O’.
    Players take turns placing their mark on an empty grid cell.
    The first to get three marks in a row (horizontal, vertical, or diagonal) wins!
    If all cells are filled and no one wins, it’s a draw.
Technologies Used:
    HTML, CSS, JavaScript
